# e-commerce
ELVYNT is a modern fashion and streetwear e-commerce website focused on minimalist aesthetics, everyday essentials, and contemporary styles. The platform showcases a curated collection of T-shirts, shirts, hoodies, trousers, and accessories through a clean, responsive, and user-friendly interface. It features product categories, new arrivals, product search, price sorting, and interactive shopping elements. Built using HTML, CSS, and JavaScript, the website aims to deliver a premium online fashion browsing experience with a focus on simplicity, style, and accessibility.
